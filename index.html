01 / Telecom & Secure Communications

Modernizing telecom.
Keeping every connection.

A secure communications platform with an aging database, hardware-bound licenses, and no room for an extended outage. I led the database migration and designed its automated recovery path.

Aurora PostgreSQL · AWS DMS · Lambda · Terraform

< 60 sec

Automated failover recovery

Zero data loss through the migration
My contribution
  • Led the database modernization: a phased, zero-downtime upgrade spanning multiple major PostgreSQL versions to Aurora PostgreSQL, planned around a legacy platform with no room for extended downtime.
  • Designed the failover architecture: replaced a manual, hardware-dependent recovery process with an automated, serverless failover path.
  • Preserved licensing continuity: engineered a networking approach that kept hardware-bound software licenses valid through the cloud transition.
  • Implemented data protection: added encryption for sensitive customer fields to support regulatory compliance requirements.

03 / Healthcare & Cost Architecture

A clinical platform,
built to grow beyond its hardware.

I decomposed a legacy clinical monolith into managed, containerized services and reduced database pressure with caching. Related cost work extended across several client engagements.

Amazon EKS · RDS · ElastiCache · CloudFront

~50%

Less direct database read load

$300K+ annual savings identified across engagements
My contribution
  • Re-architected a legacy monolith: decomposed an on-premise clinical application into containerized services running on managed infrastructure, removing the on-prem hardware dependency.
  • Reduced database load: introduced an in-memory caching layer that meaningfully cut direct database read traffic.
  • Applied cost-aware compute design: moved static server fleets to dynamic, right-sized compute across several engagements.
  • Standardized delivery pipelines: automated deployment and disaster-recovery processes to reduce manual operational overhead.
