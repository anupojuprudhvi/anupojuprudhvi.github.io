ACID Lakehouse

Multi-domain data platform

100% serverless compute with domain-isolated KMS keys and S3 Bucket Keys
Architectural contribution
  • Medallion architecture on Apache Iceberg: designed a 4-tier lakehouse (Raw → Bronze append → Silver conformed → Gold marts) with ACID guarantees, schema evolution, and min/max metadata pruning.
  • Domain-isolated security model: designed dedicated KMS customer-managed keys, scoped IAM execution roles, and 5 standardized S3 buckets per domain preventing cross-domain blast radius.
  • Serverless FinOps engineering: cut operational costs via S3 Gateway VPC Endpoints, S3 Bucket Keys (99% KMS request reduction), and dynamic Glue DPU allocation.
  • Automated audit and quarantine framework: captured corrupted records and schema mismatches into dedicated audit tables with deterministic error codes.
