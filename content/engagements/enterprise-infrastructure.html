Architectural contribution
  • Engineered a 21+ node Oracle RAC cluster on AWS: used software-defined clustered storage to emulate shared-SAN semantics across independently-attached EBS volumes, tuning ASM diskgroups and kernel I/O settings for sub-2ms latency under peak concurrency.
  • Automated end-to-end disaster recovery for enterprise mail: built a single script handling elastic IP reassociation, EBS volume reattachment, and service recovery, cutting RTO from 4+ hours to under 3 minutes.
  • Unified storage across three infrastructure environments: deployed a distributed S3-compatible object storage platform reachable from AWS, an on-prem VMware data center, and OpenStack behind one API.
  • Cut recurring storage costs by 40%: automated lifecycle tiering from hot object storage to AWS S3 Glacier while meeting multi-year audit retention requirements.
